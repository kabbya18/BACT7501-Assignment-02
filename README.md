# BACT7501 Assessment 2
## Purchase Requisition System

This project is a Purchase Requisition System
developed using Python and Object-Oriented
Programming (OOP).

## Features

- Enter staff information
- Generate unique requisition IDs
- Add purchased items and their prices
- Calculate the total purchase cost
- Automatically approve requests below $500
- Keep requests of $500 or more pending
- Allow managers to approve or reject requests
- Generate approval reference numbers
- Display requisition information
- Calculate requisition statistics

## Technologies Used

- Python
- Visual Studio Code
- Git

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Enter the command:

   py purchase_requisition.py

4. Follow the instructions in the terminal.

## Approval Rules

Requests below $500 are automatically approved.

Requests costing $500 or more require
a manager's decision.
